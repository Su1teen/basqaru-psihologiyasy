# 📖 Басқару психологиясы — Электрондық оқулық

Заманауи, ыңғайлы веб-оқулық платформасы. AutoPlay Media Studio жобасынан толық вебке көшірілген.

## ✨ Мүмкіндіктері
- **Толық оқу материалдары**: Кіріспе және 10 кешенді дәріс (теориялық негіздерден басқару шешімдеріне дейін).
- **Қос оқу режимі (Dual Reading Modes)**:
  - 📝 **Веб-мәтін режимі**: Кез келген құрылғыға бейімделген таза мәтін, қаріп өлшемін реттеу, тақырыптар (Ақ, Сепия, Қараңғы).
  - 📄 **Түпнұсқа PDF режимі**: Ресми бекітілген PDF құжатын шолу, беттерін парақтау, толық экран және тікелей жүктеп алу.
- **Автор туралы толық мәлімет**: Портрет, ресми төс белгі марапаты және толық мәтіндік академиялық деректер.
- **Толықмәтінді іздеу**: Дәрістер бойынша сөздер мен терминдерді лезде табу (Ctrl+K).
- **Жеңіл архитектура**: Vite, таза ES модульдер және 0-dependency өндірістік Node.js сервері.

---

## 🚀 Жергілікті іске қосу (Local Development)

```bash
# 1. Тәуелділіктерді орнату
npm install

# 2. Әзірлеу серверін қосу
npm run dev
```

Браузерде ашыңыз: `http://localhost:5174`

---

## 📦 Өндірістік нұсқаны жинау (Production Build)

```bash
npm run build
npm start
```
`http://localhost:3000` мекенжайында дайын қосымша іске қосылады.

---

## ⚡ Тез іске қосу (Windows)
Жоба қалтасындағы `start.bat` файлын екі рет басыңыз. Сервер автоматты түрде қосылып, браузер ашылады.

---

## 🚆 Railway-ге деплой жасау (Deploy to Railway)

1. Осы қалтаны GitHub репозиторийіңізге жіберіңіз:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/Su1teen/basqaru-psihologiyasy.git
   git push -u origin main
   ```
2. [railway.app](https://railway.app) сайтында **New Project → Deploy from GitHub repo** арқылы `basqaru-psihologiyasy` репозиторийін таңдаңыз.
3. Railway жобаны автоматты түрде анықтап, `npm start` арқылы іске қосады!
